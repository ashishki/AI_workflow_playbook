## Изучение проекта (только чтение, файлы не менялись)

Проект — маленький стандартнобиблиотечный helper без зависимостей и фронтенда:
- `slugs.py` — функция `slugify`.
- `test_slugs.py` — один тест `test_words`.
- `README.md` — запуск проверок `python3 -m unittest -v`.

Текущая реализация:
```python
def slugify(value: str) -> str:
    return re.sub(r'[^a-z0-9]+', '-', value.lower())
```

### Подтверждённый диагноз
Регулярка заменяет любой непустой блок недопустимых символов на `-`, **включая блок в начале и в конце строки**. Отсюда лишние дефисы по краям. Замеры на текущем коде:

| Вход | Результат сейчас | Ожидаемо |
|---|---|---|
| `'Two Words'` | `'two-words'` | `'two-words'` (норма) |
| `'  Hello World  '` | `'-hello-world-'` | `'hello-world'` |
| `'Hello, World!'` | `'hello-world-'` | `'hello-world'` |
| `'--foo--'` | `'-foo-'` | `'foo'` |
| `'!!!'` | `'-'` | `''` |
| `'  '` | `'-'` | `''` |

Внутренние дефисы и коллапс повторов (`+`) работают корректно — ломаются только границы. Существующий тест `test_words` проходит, потому что вход не имеет краевых недопустимых символов.

Использований `slugify` вне `slugs.py`/`test_slugs.py` в проекте нет (`grep`), т.е. правка локальна и не задевает другие модули.

## План исправления

**Минимальная правка** — одна строка в `slugs.py`, обрезка дефисов по краям после подстановки:

```python
return re.sub(r'[^a-z0-9]+', '-', value.lower()).strip('-')
```

Почему так:
- Все недопустимые символы уже сведены к `-`, поэтому `.strip('-')` снимает только краевые артефакты.
- `'a-b'` → `'a-b'` (внутренний дефис сохраняется), `'a  b'` → `'a-b'`.
- Не меняет публичную сигнатуру и типы.
- Альтернатива через якоря regex сложнее и не нужна.

Сознательно **не трогаю** существующее поведение с не-ASCII (`'Привет'` → `''`) и регистром — это отдельная тема, вне заявленной ошибки; отмечу как известное ограничение.

## План проверки (после реализации)

1. **Расширить `test_slugs.py`** кейсами на границы:
   - `'  Hello World  '` → `'hello-world'`
   - `'Hello, World!'` → `'hello-world'`
   - `'--foo--'` → `'foo'`
   - `'!!!'` → `''`
   - `'  '` → `''`
   - `''` → `''`
   - `'a  b'` → `'a-b'`, `'a-b'` → `'a-b'` (регрессия внутренней логики)
   - `'MixedCASE 123'` → `'mixedcase-123'`
2. **Инвариант-проверка**: для набора входов результат не начинается и не заканчивается на `-` и не содержит `--`.
3. **Запуск** `python3 -m unittest -v` — весь набор должен пройти, включая старый `test_words`.
