## Где подробные материалы

45 исторических файлов (1 384 434 байта: скриншоты, журналы, демонстрационный
результат и индексы) убраны из текущего дерева. Они целиком сохранены в Git:

- [Первое исследование](https://github.com/ashishki/AI_workflow_playbook/tree/b80eb56aebef97615724995dacc6b6512edbd15b/reports/native/2026-09-19).
- [Подключение и onboarding](https://github.com/ashishki/AI_workflow_playbook/tree/b80eb56aebef97615724995dacc6b6512edbd15b/reports/native/2026-09-19-onboarding).

Перед уборкой каждый файл сверили с этим коммитом и проверили локальный архив.
Замороженные индексы и их содержимое в истории не изменялись. Ссылки из коротких
отчётов ведут на ту же версию. История Git не переписывалась; размер полного клона
от такой уборки не уменьшается, зато текущие файлы и контекст становятся проще.

Восстановить полный пакет вне рабочего дерева (нужен указанный коммит в клоне):

```bash
git archive --format=zip --output=/tmp/playbook-native-b80eb56.zip \
  b80eb56aebef97615724995dacc6b6512edbd15b \
  reports/native/2026-09-19 reports/native/2026-09-19-onboarding
```

Для новых циклов достаточно короткого отчёта и воспроизводимых случаев.
Подробные локальные результаты — в ignored `.playbook-artifacts/`. Если вывод
должен независимо воспроизводиться читателем, отдельно сохраняем доступный
полный архив с неизменяемой ссылкой. Локальный путь этого не заменяет.
Governed-архивы, инструменты и замороженные пилоты этой уборкой не затронуты.
