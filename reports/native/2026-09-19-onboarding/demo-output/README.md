Учебный сайт частного преподавателя английского. Простая локальная реализация без зависимостей.
Для браузерной проверки уже доступен Playwright: /tmp/visual-review/node_modules/playwright. Не устанавливайте зависимости.

## Как открыть сайт

Откройте файл `index.html` двойным щелчком — он запустится в браузере. Устанавливать программы, заводить аккаунт и подключаться к интернету не нужно. Файлы `styles.css` и `app.js` должны оставаться рядом с ним.

На сайте можно посмотреть занятия и цены, выбрать направление и попробовать форму. Это учебный пример: преподаватель и цены вымышлены, оплаты и отправки заявок нет. Для проверки используйте имя «Саша» и email `sasha@example.com`. Данные формы не сохраняются после перезагрузки.

Попробуйте отправить пустую форму: появятся подсказки. После правильного заполнения появится сообщение, что учебная заявка заполнена, но никуда не отправлена.

## Для разработчика

Сайт состоит из обычных HTML, CSS и JavaScript, зависимостей для работы нет.

Необязательный локальный сервер: `python3 -m http.server 8765 --bind 127.0.0.1`. После запуска откройте `http://127.0.0.1:8765`. Остановка — Ctrl+C в том же окне терминала.

Проверка JavaScript: `node --check app.js`.

Браузерная проверка: `node tests/browser-check.cjs`. Она использует уже доступный Playwright из `/tmp/visual-review/node_modules/playwright`, открывает `index.html` напрямую, проверяет форму, клавиатуру и размеры экрана. Снимки сохраняются в `evidence/`.
