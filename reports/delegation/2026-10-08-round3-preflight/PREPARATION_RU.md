# Третий раунд: подготовлен, модельные прогоны NOT RUN

Подготовлен связанный синтетический проект обработки заказов, резервирования
товара и возвратов: 67 файлов, 44 исходника, 527 строк рабочего кода. Три ошибки
воспроизводятся отдельно и взаимодействуют в общем сценарии. Загрузка пакетов
событий и восстановление контрольной точки входят в работающий путь приложения.
Это средний синтетический проект, а не большой реальный репозиторий.

Закреплены шесть первых попыток A/B/C, по два повтора, одинаковая модель
gpt-6.1-sol/high и бюджет 600 секунд. B работает одним агентом; C привлекает
2–3 настоящих помощников. Исправлений по подсказкам оператора между попытками
нет. Критерий потенциальной пользы: одинаково успешные B/C, минимум 20% выигрыша
по медиане времени и максимум двукратный расход uncached input и output tokens.

Наблюдённые локальные проверки:

- 108 тестов vnext — PASS; из них 22 проверки третьего раунда.
- Контракты репозитория и соответствие runtime copies — PASS.
- Во всех шести подготовленных рабочих каталогах исходная программа действительно
  не проходит проверку исправлений; здоровый контроль проходит.
- Эталонные исправления в отдельной временной копии: 8 публичных проверок PASS,
  итоговая одинаковая оценка 100/100. Модельные рабочие каталоги не исправлялись.

**Все шесть модельных прогонов — NOT RUN. Независимое итоговое ревью — NOT RUN.**
BLOCKED в generated report означает отсутствие проверки, а не провал модели.

пакет подготовки ещё не показывает. Прежние результаты не переписывались.
