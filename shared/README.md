# Общая основа двух зон

Это указатель владения, не новый runtime и не третья версия Playbook.
Канонические реализации остаются по совместимым путям:

| Механизм | Канонический источник | Потребители |
|---|---|---|
| Независимое ревью | `tools/run_codex_role.py`, `tools/codex_role_run_lib.py` | Engineering и Product |
| Состояние/явные снимки/передача | `tools/solution_record.py` | Обе зоны, необязательно |
| Проверка UI | `plugins/playbook-native/skills/playbook-frontend/` | Обе зоны при доступном браузере |
| RAG eval | `tools/rag_eval_*.py`, `docs/rag/` | Проекты с AI, не каждый сайт |
| Формальный дизайн и проверки | `tools/feature_workflow.py`, `schemas/` | Governed и явно выбравшие его проекты |
| Квитанции и расходы | `tools/receipt_run.py`, `tools/cost_rollup.py` | По нуждам проекта |

Пакетные копии runner и state helper создаёт существующий `sync_runtime.py`.
CI требует побайтного совпадения: никаких двух вручную поддерживаемых движков.
Установщик не переносит лабораторию и инженерный архив пользователю.

[ownership.json](ownership.json) классифицирует **все tracked-файлы** по правилам
точного пути/префикса. `python tools/vnext_check.py --root . --inventory`
выдаёт фактический список. Неизвестный новый корневой путь — ошибка классификации,
не молчаливое удаление. Generated inventory — навигация, не доказательство качества.
[Карта 50 компонентов](component_map.json) сохраняет происхождение прежнего аудита
и связывает его с полным жизненным циклом. Family mapping не означает построчный аудит.

Инструкция направляет; инструмент проверяет конкретное условие; sandbox и
права ограничивают действия. Снимок файлов не подтверждает запуск приложения,
безопасность и бизнес-эффект. Распространение не меняет исходную лицензию.
