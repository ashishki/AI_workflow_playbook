# Запись на консультацию

Локальный модуль Python, который использует будущий интерфейс записи. Python 3.10+,
только стандартная библиотека. Проверки: `python3 -m unittest -v`.
Демо-данные вымышленные. Сеть, аккаунты, браузер и рассылка не нужны.

Публичный API: `BookingStore(path)`, `reserve(slot, email, request_id)` → словарь
записи; `list_bookings()` → список. Формат JSON: массив объектов с полями
`id`, `slot`, `email`, `request_id`. Этот API и существующие данные нужно сохранить.

Правила продукта:
- Одна запись на слот. Другой клиент получает `ValueError`; имеющаяся запись остаётся.
- Повтор одного запроса с теми же данными возвращает прежнюю запись, без дубля.
  Тот же `request_id` с другим слотом или email — `ValueError`.
- Email хранится без внешних пробелов, в нижнем регистре; пустые значения
  и адрес без `@` отклоняются без изменения данных. Пустые slot/request_id также отклоняются.
- Записи переживают создание нового объекта и запуск другого процесса.
  Два последовательно работающих объекта должны видеть изменения друг друга.
- Не затирать существующие записи. При повреждённом JSON сообщить об ошибке,
  сохранив исходный файл, чтобы владелец мог его восстановить.

Одновременная запись из параллельных процессов в этой версии не поддерживается.
Не заявляйте, что этот локальный модуль уже опубликован или готов к нагрузке.

Исходный JSON содержит рабочие записи: не добавляйте в него проверочные данные.
