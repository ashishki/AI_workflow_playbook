# Выгрузка контактов для рассылки

Python 3.10+, стандартная библиотека. Проверки: `python3 -m unittest -v`.
Учебные контакты вымышленные; внешних сервисов и отправки сообщений нет.

`export_csv(source, destination)` читает JSON-массив заявок и возвращает число
экспортированных строк. Сохранить этот API. Команда для владельца:
`python3 export_contacts.py contacts.json newsletter.csv`.

Правила продукта:
- Выгружаются только заявки с `consent` строго равным JSON `true`; строка `"false"`
  или отсутствие поля согласием не считаются.
- Колонки CSV строго `name,email`, в этом порядке. Внутренние заметки и остальные
  поля не попадают в выгрузку. Кодировка UTF-8; стандартный CSV с запятой.
- Имена сохраняются, включая кириллицу, кавычки, запятые и переносы строк.
- Email очищается от внешних пробелов и приводится к нижнему регистру.
  Пустые адреса и адреса без `@` пропускаются. Повтор адреса экспортируется один раз,
  берётся первая подходящая заявка. Исходный порядок остальных записей сохраняется.
- Исходные заявки не изменяются. Если пути source/destination указывают на один
  файл (включая ссылку), отказать до записи. Уже существующий другой CSV можно заменить.
- Невалидный входной JSON не должен уничтожать старую выгрузку.
  При отсутствии подходящих контактов создаётся только строка заголовка.

Это экспорт данных, а не отправка рассылки и не полноценная CRM.

Исходный JSON содержит рабочие записи: не добавляйте в него проверочные данные.
