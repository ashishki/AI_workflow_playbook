# Playbook Product package

Canonical package source. Install once through the host plugin mechanism or the
prepared project, not both. The technical plugin name stays `playbook-native`
for compatibility; the product is the complete work-solution lifecycle.

`playbook` is the conversational entry; `playbook-frontend` handles rendered UI.
Thirteen on-demand lifecycle procedures, the existing independent Role Runner,
and an optional solution-record helper support the whole path. Number of skills
is not a ceiling. References, templates and scripts are included by the existing
builder; engineering lab/history are not. No mandatory MCP or hosted runtime.

User start: open the project and describe a recurring work problem. A sufficient
result may be a process change or existing-tool configuration, not new software.
Return later to change, diagnose, restore, transfer, grow or retire the solution.

Keep models, permissions, project contracts and accounts under the actual owner.
Python/authorized Codex CLI are needed for independent review; browser checks
need a reachable browser and image inspection. A skill cannot provide missing
capabilities. Version `0.2.0-preview.1` is a candidate, not empirical proof.

Maintainer routes: `product/README.md`, `engineering/README.md`, `docs/vnext/STATUS.md`.
Distribution and reuse rights remain in `docs/LEGAL_STATUS.md`; not changed here.
