# Реальная проверка полного пути

Пилот не проведён этой публикацией. Никакие участники не приглашены, данные не
прочитаны, таймеры не включены. Материалы ниже — готовый протокол, не результаты.

Первый кандидат — [преподаватель английского](english-teacher.md). Затем 3–5 людей
с одной небольшой повторяющейся проблемой каждый. Разрешённые данные, обратимые
действия, ручной fallback, понятный владелец. Терапевтические/клиентские материалы
не превращаются в публичные fixtures; согласие на пилот и на публикацию разные.

Полный путь: понять → выбрать → сделать/настроить → проверить → внедрить →
наблюдать → изменить через время → передать → проверить восстановление/отключение.
Участник может выбрать не писать код. Сценарий без программы — полноценный результат.

Отдельно записывать:
1. Эффект на весь процесс, включая загрузку данных и исправления.
2. Реальное использование через неделю/месяц (не заполнять заранее).
3. Каждое вмешательство: владелец уточнил правило / автор организовал работу /
   специалист нужен по существу. Причина, действие, время, повторяемость.
4. Изменение в новой сессии без автора; сохранность старого поведения.
5. Полные расходы main/review/fix/eval, подписки и время человека. Unknown не ноль.

Периодически сравнивать с обычным сильным помощником при сопоставимых условиях.
Существующий Harness Lab остаётся единственным runner экспериментов. Не приписывать
Playbook выигрыш от дополнительного труда автора. Ни удачный ZIP, ни один пример
не доказывают рынок. Потеря данных, обход разрешений или ложная критическая проверка
останавливают расширение пилота до исправления. Общая раздача требует решения о правах.
