# Начать с одной рабочей проблемы

Откройте в Codex папку «Мой проект» из согласованного комплекта Playbook.
Напишите, что повторяется, где теряются время или информация и как вы решаете
это сейчас. Например: «У части заявок клиентов нет следующего действия».
Необязательно заранее просить приложение. START.html — необязательная помощь.

Playbook поможет выбрать подходящее изменение, сделать или настроить его,
проверить и встроить в работу. Существенные правила, доступы и расходы решаете вы.
Технические проверки организует помощник. Не отправляйте пароли, ключи и чужие
персональные данные в чат или общий репозиторий.

«Сначала только план» не разрешает менять файлы. «Только проверь» не разрешает
исправлять. «Сделай и проверь» продолжает обычные разрешённые шаги. Для публикации,
подключения аккаунта и необратимого изменения требуется соответствующее разрешение.

После работы откройте результат, выполните главное действие и попросите объяснить
ограничения. Позже вернитесь в ту же папку: «Измени это правило, сохранив прежние
данные». Доступны диагностика, восстановление, передача, рост и отключение решения.
Не считайте локальный пример подключённым рабочим сервисом.

Для существующего проекта попросите подключить Playbook из выбранной версии;
агент проверит конфликт инструкций и сохранит ваши изменения. Обновление и удаление
выполняются только по запросу. Одна область — один источник установленного skill.
Удаление Playbook не должно удалять ваше решение. Существующий Governed-контракт
не отменяется. При отсутствии нужного инструмента агент должен сообщить об этом.

Нужны работающий Codex и доступная среда. Для независимого review отдельно нужны
Python 3.10+ и авторизованный CLI в среде агента; вход в desktop не доказывает их
наличие. Для UI требуется браузер. Не ослабляйте защиту ради выполнения проверки.
Комплект предварительный; права и публичный выпуск определяет автор.

Если застряли: [помощь простыми словами](HELP_RU.md).
