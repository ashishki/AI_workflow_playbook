# Начать с одной рабочей проблемы

## Самый простой путь

1. Установите поддерживаемое приложение с Codex и войдите в свой аккаунт.
2. Для своей ОС откройте комплект **Playbook Desktop** и запустите `Playbook-Setup`.
3. Выберите отдельную рабочую папку или создайте новую.
4. Нажмите «Подготовить Playbook».
5. Откройте эту папку в Codex и напишите обычными словами, что в работе повторяется,
   где теряются время или информация и как вы решаете это сейчас.

Например: «У части заявок клиентов нет следующего действия». Необязательно заранее
просить приложение. Playbook сначала помогает понять проблему и выбрать достаточное
изменение. Им может оказаться правило, настройка существующего сервиса, таблица,
автоматизация, код, AI или решение ничего нового не создавать.

**Git, GitHub, VPS, Docker, Node, API-ключи и системный Python не нужны для первого
разговора.** Они появляются только если конкретное решение действительно их требует.

## Что делает мастер

Мастер подключает канонические skills и небольшой отмеченный блок инструкций только
к выбранной папке. Он не запускает модель, не публикует приложение, не подключает
рабочие аккаунты и не меняет глобальную модель/разрешения.

Если вы хотите доступный из коробки независимый code review, мастер может отдельно,
после вашего подтверждения, скачать закреплённую официальную сборку Codex CLI в
локальную пользовательскую область и провести стандартный вход. Это не проверка
самого review: реальный reviewer запускается позже в рабочей сессии.

Обновление и удаление не перезаписывают изменённые пользователем файлы Playbook.
При конфликте операция останавливается. «Вернуть установку» восстанавливает только
предыдущее состояние подключения Playbook; это **не backup данных вашего решения**.

## Работа дальше

Существенные правила, доступы, расходы и внешние последствия решаете вы.
Разрешённую локальную техническую работу помощник выполняет сам. Для публикации,
подключения аккаунта, передачи данных наружу, расходов и необратимых действий
нужно соответствующее разрешение.

После первого результата откройте его и выполните главное действие сами. Позже
вернитесь в ту же папку и скажите, например: «Измени это правило, сохранив прежние
данные». Playbook должен сверить актуальное состояние, а не зависеть от старого чата.

## Если desktop-комплект пока не работает

В OS-комплекте остаётся обычный Native ZIP как ручной fallback: распакуйте его,
откройте папку «Мой проект» в Codex и начните разговор. Не подключайте одновременно
и локальную копию skill, и тот же глобальный plugin.

Desktop-комплект остаётся private evaluation preview, пока не пройдены чистые
Windows/macOS/Linux машины, реальные вход/reviewer/browser проверки и пользовательские
пилоты. Не отключайте защиту ОС ради запуска preview.

Если застряли: [помощь простыми словами](HELP_RU.md).
