Нужна помощь ↓

Нужны компьютер, приложение с Codex и аккаунт с доступом к работе в нём. Пробный архив Playbook нужно распаковать целиком.

1

Откройте Codex

В Windows, macOS или Linux откройте приложение ChatGPT и выберите Codex. Установка и вход.

2

Выберите «Мой проект»

Создайте локальный проект и выберите папку «Мой проект» из распакованного архива основной папкой. Playbook уже находится внутри неё.

3

Дайте первую задачу

Напишите в чате Codex, чего хотите добиться. Например: «Сделай учебный сайт преподавателя и покажи, как его открыть». Если трудно начать — .

Эти шаги рассчитаны на пробный архив Playbook. Если у вас только эта страница, попросите у автора полный комплект.

Помочь сформулировать задачу — необязательно

Можно сразу написать в Codex своими словами. Здесь сохранены примеры и выбор режима, если они вам помогают.

Можно своими словами. Контекст и ограничения помогут, но заполнять техническое задание не нужно.

Изменить подход вручную

Агент покажет выбранный подход. Его можно изменить в любой момент обычной фразой.

Понятно, что осталось

Учебная форма может показывать пример заявки, не отправляя её. Агент должен явно объяснить такие ограничения.

Пример понятного ответа: «Сайт готов для локального просмотра. Проверил форму и мобильный экран. Заявки пока никуда не отправляются. Вот как открыть результат…»

У меня уже есть свой проект

Учебная папка нужна только для первой пробы. Для постоянной работы Playbook можно установить как расширение Codex. Тогда он будет доступен в ваших проектах без копирования учебной папки.

  1. Откройте в Codex саму распакованную папку «Playbook».
  2. Скопируйте запрос подключения ниже. Если Codex просит разрешение на установку, прочитайте его пояснение и используйте штатное подтверждение.
  3. После установки начните новый чат в папке вашего проекта и напишите «Playbook, помоги с задачей…».

Это пока тестовый путь: установка, обновление и удаление проверены в Codex CLI на Linux; установка через окна desktop ещё не подтверждена. При ошибке используйте помощь ниже. Не переносите учебные файлы поверх своего проекта.

Не получается начать или открыть результат

Убедитесь, что архив распакован целиком и в Codex выбрана нужная папка. Затем отправьте агенту этот запрос. Пароли и ключи доступа присылать не нужно.

Как работает автоматическое ревью

После изменений кода агент сам запускает отдельного проверяющего и исправляет подтверждённые проблемы. Быстрый режим тоже включает эту проверку. Выбирать роли и читать технические отчёты не нужно.

Для проверяющего в рабочей среде нужны Python и Codex CLI. Агент проверит их доступность. Если инструмента нет или запуск запрещён, он объяснит, какая проверка не состоялась, и следующий шаг. Не нужно самостоятельно отключать защиту.

Как продолжить завтра, исправить что-то или остановиться

Откройте в Codex ту же папку проекта. Можно написать: «Продолжим с того места, где остановились», «Исправь только эту кнопку», «Пока только предложи план» или «Остановись, файлы больше не меняй». Расширение можно удалить средствами Codex; агент поможет убрать свои настройки проекта, сохранив вашу работу.
