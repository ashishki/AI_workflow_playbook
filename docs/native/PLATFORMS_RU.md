# Windows, macOS и Linux

Цель одна на трёх системах: пользователь открывает мастер, выбирает рабочую папку,
подключает Playbook и дальше разговаривает с Codex обычным языком.

Физически поставка теперь состоит из **OS-specific desktop bundle** для Windows,
macOS и Linux. Это лучше, чем заставлять новичка предварительно ставить Python.
Внутри каждого bundle лежит один и тот же канонический Native kit; отдельный Native
ZIP остаётся переносимым ручным fallback.

## Что требуется пользователю

Для первого разбора рабочей проблемы нужны только поддерживаемая AI-среда/Codex,
вход в свой аккаунт и выбранная рабочая папка. Git/GitHub/VPS/Docker/Node/API key
не являются общей установкой Playbook.

Полный независимый Role Runner может использовать локальный `playbook-helper`,
в который включён Python runtime сборки. Если в текущей среде нет пригодного Codex
CLI, мастер может после явного согласия скачать закреплённый официальный release
OpenAI в per-user каталог и проверить SHA256/размер. Глобальный PATH, модель и
credentials не переписываются. Сам вход остаётся отдельным действием владельца.

Наличие бинарника и даже успешный login-status не означают, что реальный reviewer,
браузер или бизнес-интеграция работают. Эти проверки выполняются отдельно на
фактическом проекте.

## Что проверять на каждой ОС

| Уровень | Что проверяем | Чего это не доказывает |
|---|---|---|
| Source tests | install/update/remove/rollback, сохранение пользовательских файлов, пакет и helper | работу frozen binary и GUI |
| Frozen self-test | реальный собранный helper устанавливает/удаляет тот же kit и запускает inventory | модель, браузер, удобство |
| Clean-machine trial | запуск мастера, выбор папки, вход, настоящий review, пути с пробелами/кириллицей | пользу конкретному человеку |
| User pilot | первый результат, возврат позже, изменение и передача | неограниченную совместимость |

Native preview ранее имел успешную CI-проверку на трёх ОС. Новая Desktop-поставка
не наследует этот статус автоматически: её matrix job и clean-machine наблюдения
должны пройти отдельно.

## Важное ограничение preview

Собранные здесь desktop-бинарники не считаются подписанным публичным релизом.
На Windows/macOS могут действовать системные предупреждения доверия. Не просите
тестера отключать SmartScreen, Gatekeeper или другие защиты. Для публичного выпуска
отдельно решаются signing/notarization, права и канал обновления.

При проблеме достаточно сообщить ОС, версию Codex/Playbook, шаг и текст ошибки.
Пароли, токены, auth-файлы и клиентские данные для диагностики не нужны.
