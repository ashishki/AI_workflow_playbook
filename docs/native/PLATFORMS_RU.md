# Windows, macOS и Linux

Для всех трёх систем используем один ZIP. Распакуйте его штатным архиватором,
откройте папку «Мой проект» в Codex и напишите задачу. `START.html` — необязательная
помощь с первым запуском; задачу выполняет Codex. Для существующего проекта есть
отдельный запрос подключения на той же странице.

Актуальная [официальная инструкция Codex](https://learn.chatgpt.com/docs/quickstart?setup=app)
описывает вход для Windows, macOS и Linux. Наличие инструкции не заменяет проверку
на конкретном компьютере. Версию приложения и доступность нужных возможностей
проверяем в сессии пользователя.

## Что нужно для автоматического ревью

Обычную работу выполняет агент в Codex. Для включённого независимого Role Runner
в этой же среде нужны Python 3.10+ и авторизованный Codex CLI. На Windows доступная
команда Python может называться `py -3`; на macOS/Linux — `python3`. Агент сам
проверяет команды. Пользователю не нужно выбирать роли и запускать ревью вручную.

Вход в desktop сам по себе не подтверждает доступность CLI. Если среда запрещает
вложенный процесс, агент сообщает, что независимое ревью не состоялось, сохраняет
журнал и предъявляет остальные выполненные проверки. Он не меняет разрешения,
учётные данные или глобальную модель ради прохождения проверки.

## Какие проверки различаем

| Проверка | Что она подтверждает | Что ещё не подтверждено |
|---|---|---|
| CI на Windows, macOS, Linux | Сборка и распаковка ZIP, пути с кириллицей/пробелами, контракты Role Runner с fake CLI, START в Chromium | Вход пользователя в Codex и настоящее ревью моделью на каждой ОС |
| Реальный CLI на Linux | Исполнение модели, обнаружение skills и результаты конкретных задач | Desktop на трёх системах и удобство для новичка |
| Проход человека в desktop | Установка, первый запрос, открытие результата и продолжение работы | Неограниченная совместимость со всеми версиями и конфигурациями |

[CI на трёх системах прошёл](https://github.com/ashishki/AI_workflow_playbook/actions/runs/35448960785)
для `1cf494a`: все три package jobs и интеграция Harness Lab успешны; ZIP имеет
одинаковый SHA256 на трёх ОС.
Остальные результаты находятся в [отчётах](../../reports/native/README.md).
Объявленная поддержка трёх систем — цель
доставки; непроведённые проверки не считаем успешными. До desktop-пилота комплект
остаётся preview. Сценарий и короткая таблица наблюдений: [PILOT_RU.md](PILOT_RU.md).

## Как сообщить проблему

Достаточно написать систему, версию Codex, версию комплекта, шаг, который не
получился, и текст ошибки. Пароли и ключи не нужны. Если агент уже выполнял
ревью, пусть кратко объяснит его статус и сохранит исходный журнал локально.
