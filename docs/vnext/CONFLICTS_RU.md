# Согласование старых и новых путей

| Раньше можно было прочитать так | Теперь |
|---|---|
| Весь репозиторий — Native для новичков | Два входа: реальное Engineering-использование и полный Product-путь |
| Engineering только создаёт и проверяет методику | Также ежедневное создание новых и развитие текущих проектов |
| Native навсегда ограничен двумя skills | Полнота определяется 13 стадиями; число файлов не цель |
| Установка Native отменяет сложные правила | Действующий контракт сохраняется; явная миграция отдельно |
| Orchestrator никогда не пишет рядом с Direct | Для текущего прямого профиля main реализует; reviewer отдельно; legacy не активируется молча |
| `validated` runner = код принят | Валидность исполнения, verdict и устранение findings — разные факты |
| Новый каталог разрешает автоматически отправлять данные | Нет: права среды/аккаунта/операции независимы от capability |
| Новый package test = польза человеку | Mechanism / live workflow / user outcome измеряются отдельно |

Старый мануал сохранён для использующих его проектов; его исторические универсальные
правила не автоматически импортируются в Product. Мы не переписываем прежние
доказательства, не исправляем их «статистику», не отключаем действующие CI-гейты.
Подробные ссылки на исходные поверхности сохранены в shared/component_map.json.
