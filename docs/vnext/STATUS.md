## Следующее действие без перезапуска проекта

Прочитать текущий PR/Actions на точном HEAD, исправить реальные дефекты;
провести независимое ревью в разрешённой среде по действующему Role Runner.
Затем пройти полный Product-кейс и второе изменение/передачу без автора.
Не включать скрытые таймеры и не приглашать участников без разрешения.
Не менять master/downstream, лицензирование, глобальную модель и полномочия.
Новые сценарии пользователя не считать заранее успешно пройденными.

Rollback: revert коммитов vNext. Данных production и миграций нет. Пользовательские
решения не обновлялись; экспериментальная ветка не меняет установленный у них пакет.
