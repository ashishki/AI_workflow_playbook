# vNext — фактическое состояние

База `1e0abe0048daefc30d2f7f9276ab12246bda6856`.
Ветка `feature/playbook-vnext-20260919`; [PR №9](https://github.com/ashishki/AI_workflow_playbook/pull/9).
Это переработка репозитория и пакета, не завершённый внешний пилот.

## Реализовано

Два действующих входа: Engineering для новых/текущих реальных проектов и отдельных
экспериментов; Product для полного пути рабочей проблемы. Общая основа по совместимым
путям; исходные runner/frontend/Governed сохранены. Все tracked-пути классифицируются,
50 прежних компонентов сопоставлены с жизненным циклом. Все 13 стадий доступны как
вызываемые процедуры и входят в архив. Необязательный solution record проверяет
структуру и внутреннюю согласованность, показывает итог, фиксирует выбранные файлы
и обнаруживает устаревание перед передачей. Никакие команды из записки не исполняются.
Версия `0.2.0-preview.1`. Старые продуктовые документы сохранены побайтно; frozen
experiments, master, текущие downstream и права распространения не менялись.

## Наблюдённые проверки

На `cca2a31` [Native CI](https://github.com/ashishki/AI_workflow_playbook/actions/runs/35464210239)
прошёл: существующий Harness Lab adapter, пакет/reviewer checks, новые проверки и
реальная Chromium-проверка извлечённого START на Windows/macOS/Linux.
[vNext CI](https://github.com/ashishki/AI_workflow_playbook/actions/runs/35464210232)
проверяет полный tracked inventory, сохранённые исходники и delivery на Python 3.10/3.13.
Точный итог нового HEAD после этого файла смотреть в Actions/PR; прошлый PASS не
приписывается автоматически последующему коммиту.

Первый CI выявил различие LF/CRLF у новой канонической копии Windows; добавлено
точное правило `.gitattributes`, сравнение байтов не ослаблено. Проверка состояния
дополнена отказом от `checked`, когда есть `not_run`.

Изначально в контейнере были только новые файлы (26 локальных tests PASS). Позже
получен точный source archive через GitHub CI, проверен SHA256 транспортного архива.
На извлечённом исходнике прошла полная классификация. Прочитаны реальные скриншоты
390/1280. Локальный расширенный Engineering run остановлен лимитом 120 секунд,
не считается PASS. Отдельно обнаружена и исправлена регрессия обязательной ссылки
и английского legal notice в README без изменения прав или ослабления теста.
Расширенная Engineering-регрессия теперь отдельно включена в CI.

## Что не завершено и почему

Независимый review изменений **не проведён**: Codex CLI отсутствует в среде этой
реализации. Собственное чтение/тесты и fake CLI не заменяют независимого reviewer;
PR остаётся draft. Реальный разрешённый Codex/browser/reviewer workflow новых
процедур и самостоятельность человека тоже не доказаны. Участники, аккаунты и
разрешённые примеры не подключались; платных model trials не было.

M0–M3 реализованы как модель, маршруты, классификация и общие реализации.
M4 реализован как полная библиотека и helpers; Markdown не доказывает поведение модели.
M5–M6 **ожидают реального кейса и мини-группы**, протоколы готовы в `product/pilots/`.
M7: логическое разделение завершено; совместимые физические пути намеренно сохранены.
Массовый перенос файлов не является обязательной недоделкой.

## Продолжение

Сначала текущий PR/CI и независимый review изменённых механизмов в разрешённой
среде. Затем полный Product-кейс, повторное изменение/передача без автора,
диагностика/восстановление на копии и наблюдение эффекта. Не начинать старую CF-очередь
и не пересоздавать эти папки. Не обходить запреты, не включать таймеры, не приглашать
участников и не менять модель/master/downstream без соответствующей задачи.

Rollback — revert коммитов vNext. Production-данные и установленные у пользователей
решения не менялись. CI-артефакты — диагностический комплект, не публичный релиз.
